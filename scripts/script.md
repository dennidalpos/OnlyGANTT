# Script inventory

All operational scripts are under `scripts/`. Files in `scripts/support/` are internal helpers and are not intended as direct user entrypoints unless a package or lifecycle validation command calls them.

| Name | Path | Function | When to use it | Invoked by | Dependencies/prerequisites | Compatibility/migration notes |
| --- | --- | --- | --- | --- | --- | --- |
| install dependencies | `scripts/install-dependencies.ps1` | Runs `npm ci` and creates the artifact layout. | Fresh checkout or dependency reset. | `npm run bootstrap` | PowerShell 7+, npm, `package-lock.json` | Replaces `scripts/bootstrap.ps1`; npm command is unchanged. |
| check environment | `scripts/check-environment.ps1` | Validates Node.js, npm, dotnet, required sources, service/packaging inputs and `node_modules`. | Before build, test, package or troubleshooting setup. | `npm run doctor`, `scripts/build-project.ps1`, `scripts/test-project.ps1`, `scripts/gate.ps1` | PowerShell 7+, Node.js >= 20, npm, dotnet, installed dependencies | Replaces `scripts/doctor.ps1`; npm command is unchanged. |
| build runtime | `scripts/build-runtime.ps1` | Builds the browser bundle, publishes the Windows service host and writes `artifacts/build/runtime-manifest.json`. | Build runtime artifacts without packaging. | `npm run compile`, `npm start` through `prestart`, `scripts/build-project.ps1`, `scripts/test-project.ps1` | Node.js, dotnet, esbuild from `node_modules` | Replaces `scripts/compile.ps1`; npm command is unchanged. |
| build project | `scripts/build-project.ps1` | Runs environment checks and runtime build. | Standard build command. | `npm run build`, `scripts/package-project.ps1` | Same as check/build runtime | Replaces `scripts/build.ps1`; npm command is unchanged. |
| test project | `scripts/test-project.ps1` | Runs smoke, security, admin-flow, client-logic, prerequisite and Windows service lifecycle checks. Writes `artifacts/test-results/summary.json`. | Canonical regression validation. | `npm run test`, `scripts/gate.ps1` | Build prerequisites; administrator privileges only for the service lifecycle check, which skips otherwise | Replaces `scripts/test.ps1`; npm command is unchanged. |
| package project | `scripts/package-project.ps1` | Builds the project, creates the x64 MSI and setup EXE, optionally runs elevated MSI lifecycle validation. | Release/package validation. | `npm run pack`, `scripts/gate.ps1` | Build prerequisites, WiX 3.14.1 cache or network to provision it, Node.js MSI prerequisite cache or network to provision it | Replaces `scripts/pack.ps1`; npm command is unchanged. |
| publish packages | `scripts/publish-packages.ps1` | Copies existing package artifacts to `artifacts/publish/local/` and writes a publish manifest. | Publish already-built local artifacts. | `npm run publish` | Existing files under `artifacts/packages/` | Replaces `scripts/publish.ps1`; npm command is unchanged. |
| clean artifacts | `scripts/clean-artifacts.ps1` | Cleans managed artifact roots, stale output directories and optional runtime/service state. | Local cleanup. | `npm run clean` | PowerShell 7+; administrator privileges only with `-IncludeService` | Replaces `scripts/clean.ps1`; npm command is unchanged. |
| gate | `scripts/gate.ps1` | Runs preflight, tests and package build in sequence, failing at the first error. | Final local validation after dependencies are installed. | `npm run gate` | Same prerequisites as `test-project.ps1` and `package-project.ps1` | New canonical gate script. No lint/typecheck step exists in the repo today. |
| manage service | `scripts/manage-service.ps1` | Installs, starts, stops, uninstalls or cleans the native Windows service. | Manual service management. | `npm run service:*`, `scripts/support/test-windows-service-lifecycle.ps1`, installed MSI service operations | Administrator privileges, Node.js, published service host for install | Replaces `scripts/windows/service.ps1`; npm commands are unchanged. |
| generate brand assets | `scripts/generate-brand-assets.ps1` | Regenerates versioned logo, icon and social/setup bitmap assets. | Only when brand assets need deterministic regeneration. | Manual docs command | PowerShell 7+, `System.Drawing` availability on Windows | Replaces `scripts/assets/generate-brand-assets.ps1`. |
| common helpers | `scripts/support/common.ps1` | Shared PowerShell helpers for paths, command checks, artifact layout and UTF-8 writes. | Internal only. | Primary scripts and packaging support scripts | PowerShell 7+ | Replaces `scripts/helpers/common.ps1`. |
| build client bundle helper | `scripts/support/build-client-bundle.mjs` | Runs esbuild for `src/client/bundle-entry.jsx`. | Internal only. | `scripts/build-runtime.ps1` | Node.js, `esbuild` in `node_modules` | Replaces `scripts/helpers/build-client-bundle.mjs`. |
| build MSI helper | `scripts/support/packaging/build-msi.ps1` | Stages app files and builds the x64 MSI with WiX. | Internal package step. | `scripts/package-project.ps1`, MSI upgrade validation | Built runtime artifacts, WiX tools, brand icon, license, demo data | Moved from `scripts/packaging/build-msi.ps1`. |
| build setup helper | `scripts/support/packaging/build-setup.ps1` | Builds the setup bootstrapper EXE with the bundled official Node.js prerequisite chained before the app MSI. | Internal package step. | `scripts/package-project.ps1` | Built MSI, WiX tools, Node.js prerequisite MSI | Moved from `scripts/packaging/build-setup.ps1`. |
| prerequisite helpers | `scripts/support/prerequisites.ps1` | Shared Node.js runtime detection, minimum-version validation and actionable prerequisite messages. | Internal only. | `scripts/check-environment.ps1`, `scripts/manage-service.ps1`, `tests/prerequisite-regression-check.ps1` | PowerShell 7+ | New shared preflight helper. |
| packaging common helpers | `scripts/support/packaging/common.ps1` | Shared MSI lifecycle helper functions. | Internal only. | MSI lifecycle test helpers | Administrator privileges for lifecycle operations | Moved from `scripts/packaging/common.ps1`. |
| provision Node prerequisite | `scripts/support/packaging/provision-node.ps1` | Downloads/reuses and SHA256-verifies the Node.js 24.15.0 x64 MSI prerequisite. | Internal setup package step, or manual cache refresh. | `scripts/support/packaging/build-setup.ps1` | Network access if cache is absent, PowerShell 7+ | Moved from `scripts/packaging/provision-node.ps1`. |
| provision WiX tools | `scripts/support/packaging/provision-wix.ps1` | Downloads/reuses WiX 3.14.1 binaries under `tools/wix314-binaries/`. | Internal MSI/setup package step, or manual cache refresh. | MSI/setup packaging helpers | Network access if cache is absent, PowerShell 7+ | Moved from `scripts/packaging/provision-wix.ps1`. |
| test MSI install | `scripts/support/packaging/test-msi-install.ps1` | Installs an MSI silently and validates install files, registry and service state. | Elevated lifecycle validation only. | `scripts/package-project.ps1 -RunMsiLifecycleValidation` | Administrator privileges, Windows Installer, built MSI | Renamed from `scripts/packaging/msi-install-test.ps1`. |
| test MSI upgrade | `scripts/support/packaging/test-msi-upgrade.ps1` | Builds two MSI versions and validates upgrade behavior. | Elevated lifecycle validation only. | `scripts/package-project.ps1 -RunMsiLifecycleValidation` | Administrator privileges, packaging prerequisites | Renamed from `scripts/packaging/msi-upgrade-test.ps1`. |
| test MSI uninstall | `scripts/support/packaging/test-msi-uninstall.ps1` | Installs and uninstalls an MSI, then validates cleanup. | Elevated lifecycle validation only. | `scripts/package-project.ps1 -RunMsiLifecycleValidation` | Administrator privileges, Windows Installer, built MSI | Renamed from `scripts/packaging/msi-uninstall-test.ps1`. |
| test Windows service lifecycle | `scripts/support/test-windows-service-lifecycle.ps1` | Installs, starts, probes, stops and removes a validation service; skips outside elevated Windows. | Internal regression check. | `scripts/test-project.ps1` | Windows, administrator privileges, free validation TCP port | Moved from `tests/windows-service-lifecycle-check.ps1`. |
